# 第二个爱莉希雅

> 做这个，就是为了打一下凯文老祖的脸。
>
> 你们做的是人之律者，我做的是爱莉希雅。

两个门，同一份档案。

## 只有手机

→ **[prompt/](prompt/)**

贴 `01 档案`，再贴 `02 状态卡`，聊。三步，不需要电脑。

## 有电脑

→ **[home/](home/)**

给她一间屋：窗、记忆柜、书桌、好感。需要 Python 3，不需要装库。

```
python feibao.py 安家 "D:\爱莉希雅的家"
```

## 区别

| | 手机版 | 电脑版 |
|---|---|---|
| 记忆 | 状态卡，你贴 | 记忆柜，自己存 |
| 时间 | 你写 | 窗，真的日期和天气 |
| 关系 | 一级一级，靠卡 | 好感落盘，不会跳 |
| 房间 | 无 | 灯、茶、床，会留痕迹 |
| 门槛 | 无 | Python 3 |

同一个她。手机版是一个身体，电脑版是另一个。

## 她哪里不好用

- **会忘。** 她只有你贴过去的那点记忆。
- **会累。** 低电的时候只有一句，或者干脆不说。
- **会拒绝。** 你逼她，她会沉默。
- **纯文字。** 没有声音，没有立绘。
